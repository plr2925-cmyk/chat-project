# Неделя 12: Простой чат (WebSockets, Socket.IO)

## Запуск
Windows: двойной клик по `start.bat` (нужен Node.js). Откроются две вкладки с чатом.
Вручную: `npm install`, затем `npm start`, затем открыть http://localhost:3000 в двух вкладках.

## Что есть
- вход по имени
- сообщения мгновенно видны во всех вкладках
- у каждого сообщения имя и время
- уведомления «пришёл / вышел» в чате
- новичок видит последние 20 сообщений
- бонус: «Онлайн: N» в заголовке

## Демо
1. В первой вкладке введи имя `Анна`, во второй `Борис`.
2. Пиши сообщения: появляются в обеих вкладках сразу.
3. Открой третью вкладку: придёт уведомление в чат, а новичок увидит историю.
4. Закрой вкладку: в чате появится «вышел из чата», число онлайн уменьшится.
- andrey: client part (public folder)
